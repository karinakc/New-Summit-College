# 🎓 New Summit College Website

## 📌 About the Project
This project is a modern and responsive college website designed to showcase academic programs, campus information, and student resources for New Summit College. The website provides a clean user interface, interactive layouts, and an improved user experience for students and visitors.

It was built to demonstrate modern web development practices, responsive design, and UI/UX implementation.

## ✨ Features
- Modern and responsive design
- Interactive and user-friendly interface
- Academic programs showcase
- College information and services section
- Smooth navigation and layout
- Optimized performance
- Mobile-friendly design

## 🚀 Tech Stack
- React.js
- Tailwind CSS
- Responsive
